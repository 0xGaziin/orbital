## 🧐 About the Project
Orbital was born from the need for a smarter way to organize academic life. It moves away from scattered notes and fragmented tools, providing a unified ecosystem where subjects, focus sessions, and performance analytics coexist.

## ✨ Key Features
- **Subject Management:** Organize your curriculum by categories, semesters, or priority levels.
- **Smart Pomodoro Timer:** Built-in focus timer to manage deep work sessions and rest intervals.
- **Deep Work Analytics:** Track peak productivity hours and identify subjects that demand more mental energy.
- **Markdown Notes:** Create structured documentation with support for rich formatting.
- **Space Repetition (SRS):** Science-based review cycles to enhance long-term memory retention.
- **Kanban Boards:** Manage assignments and projects with a dynamic drag-and-drop system.
