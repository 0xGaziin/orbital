# 🚀 Orbital

**Orbital** is a high-performance study management platform designed for centralized, distraction-free academic organization.

## ✨ Features
- **Subject Management:** Organize curriculum by priority.
- **Pomodoro Timer:** Built-in focus and rest intervals.
- **Deep Work Analytics:** Track productivity and mental energy.
- **Markdown Notes:** Structured documentation support.
- **Space Repetition:** Science-based review cycles.

## 🛠 Tech Stack
- **Frontend:** React.js & CSS Modules
- **Backend:** Node.js & MySQL
- **Tools:** Git & GitHub

## 🚀 Quick Start
1. `git clone https://github.com/0xGaziin/orbital.git`
2. `npm install`
3. `npm run dev`
